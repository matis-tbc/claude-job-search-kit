# Audit, 2026-11-18: private system vs. this kit

The kit is the public, generic copy of a private career-coach setup that one person runs every day.
This audit lists every feature and learned rule in the private system, whether the kit had it before
this branch (`apply-loop-2026-11-18`), whether it has it now, and what changed. Personal specifics
(names, companies, numbers, dates, accounts) were generalized or left out; the last table says what
stays private and why.

Legend: **yes** = in the kit, **partial** = the idea is there but not the full rule or mechanic,
**no** = missing.

## Still private-only, and why

| Item | Why it stays out |
|---|---|
| The owner's profile, lanes, phase dates, home region, resume variants and file names | Personal. The kit reads all of these from the user's own config and vault |
| Proof-point table, blocked-number list and the Fact Sheet itself | Personal facts. The kit has the generic `[[proofs]]` table and Fact Sheet template |
| Named connectors, sponsor contacts, friends list and their companies | Real people |
| Sourcing seed lists from the owner's vault and other private repos | Personal research and other projects |
| Evals (graded prompts) | Built on the owner's target companies and vault paths. A generic eval set would need new fixtures |
| Paid email-finder lookups the owner opted into | The kit keeps its no-paid-credits rule. A user who wants one can change that rule for themselves |
| Account-specific timing (trial end dates, credit burn deadlines, batch dates, baseline metrics) | Time-bound and personal |
| Email-account routing between the owner's inboxes | Personal accounts |
